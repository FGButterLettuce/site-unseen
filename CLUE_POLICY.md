# Clue policy

Every clue must pass this checklist before it is published.

- Use an original reconstruction, not a raw authenticated screenshot.
- Use only public, logged-out interface patterns as visual reference.
- Replace all names, messages, addresses, avatars, account identifiers, order numbers, and other personal data with synthetic content.
- Remove embedded metadata and external image links.
- Do not reproduce private dashboards, internal tools, paywalled pages, or security-sensitive flows.
- Keep the crop transformative and limited to what the guessing game needs.
- Record the creator and review date in the pull request or commit message.
- Remove or revise a clue promptly when a rights holder raises a reasonable concern.

Community submissions should include the target answer, acceptable aliases, three proposed crops, and confirmation that the SVG contains no personal or confidential information.
